# Intelbras Mibo for Home Assistant

Planned standalone custom integration for Home Assistant, initially supporting
cloud control of the first key on the Intelbras Mibo EIW 1003 switch.

This repository is being bootstrapped. No working integration is available yet.
The integration will be independent of the Mibo CLI, with a layout intended for
future HACS installation.

Development will target the official Home Assistant 2026.10.4 release. Automated
tests will use fakes, without real accounts or sessions. Setup, supported behavior,
and verification commands will be documented when implementation is planned.
